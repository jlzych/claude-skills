# Skill Extractor

Extract meaningful, reusable skills from conversation history and generate properly formatted skill files.

## What It Does

Conversation patterns often reveal valuable, reusable workflows and problem-solving approaches. This skill captures those patterns by:

1. Analyzing conversation history to identify patterns worth preserving
2. Evaluating extracted patterns against existing skills to avoid duplication
3. Structuring patterns in the proper skill format with frontmatter and instructions
4. Generating ready-to-use skill files for your skill library

## Usage

```
/skill-extractor
```

This analyzes the current conversation and guides you through extracting one or more reusable skills.

## When to Use

- After completing a complex, multi-step workflow you might repeat
- When you notice a pattern that could help with future similar tasks
- To formalize ad-hoc processes into documented, reusable skills
- When capturing expertise that should be persistent across sessions

## Benefits

- **Preserve expertise**: Workflows and approaches don't get lost after the session ends
- **Reduce repetition**: Future similar tasks become faster and more consistent
- **Improve quality**: Standardized approaches ensure better outcomes across projects
- **Knowledge capture**: Implicit expertise becomes explicit, shareable knowledge
